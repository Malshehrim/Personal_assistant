# Flask Application

Simple web app that help user to create his owne tasks and trak it, usuing **Python** and **Flask**.

---

##  Features
- Flask REST API with GEMINI
- JSON to collect data
- Easy to run and extend
- Dashboard for add or delete task
- Completed page for completed task monitoring
- AI assistant to help you in your tasks

---

##  Requirements
- Python 3.9+
- Flask

---
**Note** 
Setup Instructions
1. API Key
To enable the AI features, you need to add your Google Gemini API Key.
Open the file 
.env
 in the project folder..
Replace the text with your key:
GEMINI_API_KEY=your_actual_api_key_here
## Installation

2. Run the Application
Open your terminal and run:

python app.py
